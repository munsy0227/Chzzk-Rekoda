# CHZZK Rekoda（Chzzk-Rekoda）

**言語:** [한국어](README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

Streamlink と FFmpeg を使用して作られた、Windows、macOS、Linux 対応の CHZZK 自動録画プログラムです。

また、パソコンに詳しくない方でも簡単に使える **CHZZK 自動録画プログラム**です。  
配信が始まると自動的に録画を開始し、配信が終了すると自動的に保存します。

新機能の追加、バグ修正、パフォーマンスの改善、ドキュメントの充実など、さまざまな貢献のための [Pull Request](https://github.com/munsy0227/Chzzk-Rekoda/pulls) を歓迎します。

## 1. GUI から始める

GUI は既存の CLI と同じ `config.json` を使用します。

1. [以下のインストール手順](#installation)に従い、最後の選択画面で **1. GUI** を選んでください。インストール後にアプリが開きます。
2. GUI 初回起動時に、言語・チャンネル検索・保存先を設定するウィザードが表示されます。完了時に保存し、チャンネルは後から追加できます。**ヘルプ → 初期設定**から再度開けます。
3. **ホーム → 自動録画開始** を選びます。有効なチャンネルの配信開始を待ち、録画を開始します。後から **チャンネル追加** でチャンネルを追加できます。

### 次回から GUI を開く

| OS | 起動方法 |
| --- | --- |
| Windows | `chzzk_gui.vbs` をダブルクリック · CMD 画面は表示しません（`chzzk_gui.bat` も同じランチャーを使用） |
| Linux | `Chzzk-Rekoda.desktop` をダブルクリック · 求められた場合は実行を許可 |
| macOS | インストール先のターミナルで `./chzzk_gui` を実行 |

macOS/Linux では `./chzzk_gui` も利用できます。既存の CLI 環境に GUI を追加する場合や uv から直接起動する場合は、次のコマンドを使います。Qt は GUI の利用時だけ必要です。

```bash
uv run --extra gui chzzk_gui.py
```

### リボンで設定を変更する

| 操作 | メニュー |
| --- | --- |
| ファイル形式と分割間隔 | **録画設定 → 基本録画** |
| 解像度と FPS | **録画設定 → 画質** |
| H.264・HEVC・AV1 エンコード | **録画設定 → H.264 / HEVC / AV1** |
| チャンネル別の保存先・分割・画質 | **チャンネルを右クリック → チャンネル編集** |
| ログイン Cookie の取得 | **録画設定 → NAVER ログイン** |
| 言語・ログ・バックグラウンド動作 | **録画設定 → アプリ・バックグラウンド** |
| 録画ファイルを処理して終了 | **録画設定 → アプリを完全に終了** |

**設定を保存** で変更を反映します。項目にポインターを置くか、説明ボタン/F1 でヘルプを表示できます。

### NAVER ログインが必要な配信

GUI にはデスクトップ環境と FFmpeg が必要です。**ログイン画面を開く**で CLI のブラウザーログイン手順を直接開始します。ブラウザーでログインし、別の CLI 画面で Enter を押すと Cookie が GUI に戻ります。**設定を保存**で適用します。GUI の CMD 画面は表示せず、ログイン時だけ別の CLI 画面を開きます。

<details>
<summary>画質・コーデック・プレビュー・トレイなどの詳細を見る</summary>

- リボンからチャンネル名・ID による検索、追加・編集・登録解除、すべての録画設定を操作できます。設定にポインターを置くか F1・説明ボタンでヘルプを表示します。
- CHZZK のプロフィール画像をチャンネルアイコンに使用し、取得できない場合は名前の先頭文字を表示します。
- **選択したチャンネルの録画中ファイルから5秒ごとに画像を更新**します。音声は再生しません。データ不足や読取失敗時は案内を表示して再試行します。プレビューを無効にしても録画は続きます。
- 既定ではウィンドウを閉じてもシステムトレイで録画を続けます。アイコンから再表示や**終了**ができます。アプリ設定で無効にでき、トレイがない環境では閉じると終了します。CLI/GUI の重複録画と設定の上書き競合を防止します。
- 保存した録画設定は新しい録画タスクに適用されます。DNS とログファイル保存の変更は録画プロセスを停止して再起動すると反映されます。

- チャンネル名と状態の間に元の配信タイトルを表示します。右クリックで設定・登録解除・保存先・自動録画の有効化を操作できます。
- 分割間隔と画質は全体設定の継承またはチャンネル別指定ができます。分割をオフにしたチャンネルは1ファイルに保存します。
- 提供される `144p`、`360p`、`480p`、`720p60`、`1080p60` を直接取得します。別の解像度はエンコードし、FPS のみ変更する場合は同じ解像度の映像を使います。選択したコーデック、未選択なら H.264（WebM は VP9）で変換します。提供されない画質は近い上位画質または最高画質から変換します。
- H.264 は libx264/NVENC/QSV/AMF/VAAPI/VideoToolbox に対応し、HEVC・AV1 と1つだけ選択できます。ハードウェア失敗時は libx264 を試します。H.264+WebM は MKV に保存します。
- 長いファイル名を短縮しハッシュを付けた場合だけ、動画や各分割ファイルの隣に元のタイトルを UTF-8 `.txt` で保存します。短いタイトルでは TXT を作成しません。
- GUI は `font/02_NotoSansCJK-TTF-VF/Variable/OTC/NotoSansCJK-VF.ttf.ttc` を使用し、言語に応じて KR/JP/SC/TC を選びます。Windows は DirectWrite とモニター別 DPI を使用します。配布フォルダーに `LICENSE` を同梱します。
- **録画設定 → アプリを完全に終了**は録画ファイルの処理を待ってトレイも終了します。分割録画の容量は現在の録画で作成した全分割ファイルの実サイズの合計です。
- GUI の録画が停止すると、停止コマンド、アプリ終了、通信接続のエラーなどの理由をログに区別して表示します。ファイルログが有効なら、設定ファイルの隣の `log.log` でも確認できます。
- ウィンドウ・タスクバー・トレイで同じアプリアイコンを使用します。Windows で `chzzk_gui.vbs` を実行すると、インストール先にアイコン付きの **`Chzzk Rekoda.lnk`** ショートカットを作成します。Linux では GUI 起動時にユーザーのアプリメニューへアイコンとランチャーを登録します。

<a id="installation"></a>

## 2. インストール

**[プログラムの ZIP をダウンロード](https://github.com/munsy0227/Chzzk-Rekoda/archive/refs/heads/main.zip)** · **[GitHub リポジトリ](https://github.com/munsy0227/Chzzk-Rekoda)**

使用している OS（Windows、Mac、Linux）に合った説明を読んで、手順に従ってください。
インストール中に言語選択画面が表示されたら、最初に使用したい言語を選択してください。

### Windows ユーザー

**ステップ 1: プログラムをダウンロード**

1. 上の **プログラムの ZIP をダウンロード**を選ぶか、GitHub リポジトリで緑色の **[Code]** ボタンを押してください。
2. Code メニューを使った場合は **[Download ZIP]** を押してください。上の直接ダウンロードリンクを使った場合、この手順は不要です。
3. ダウンロードしたファイルを解凍してください。（見つけやすい「デスクトップ」などをおすすめします。）

（Git を使用できる場合は Git を使用してください。）

**ステップ 2: インストーラーを実行**

1. 解凍したフォルダーに入ります。
2. `install.bat` ファイルを探してダブルクリックで実行してください。
3. 黒いウィンドウが表示され、必要なファイルが自動的にインストールされます。少し時間がかかる場合があるのでお待ちください。
4. インストールの最後に **GUI / CLI** を選択します。GUI はインストール後に画面を開き、CLI はターミナルの設定メニューを開始します。

---

### macOS / Linux ユーザー

**ステップ 1: ターミナルを開く**

- **Mac:** `Command` + `Space` キーを押し、「ターミナル」と検索して実行してください。
- **Linux:** 使用しているターミナルアプリを実行してください。

**ステップ 2: コマンドを入力**
以下のコマンドを 1 行ずつコピーしてターミナルに貼り付け、Enter を押してください。

1. **プログラムをダウンロード**
   ```bash
   git clone https://github.com/munsy0227/Chzzk-Rekoda.git
   cd Chzzk-Rekoda
   ```

2. **FFmpeg をインストール（録画に必須）**
   - **Mac ユーザー（Homebrew が必要）:**
     ```bash
     brew install ffmpeg
     ```
   - **Ubuntu/Debian ユーザー:**
     ```bash
     sudo apt install ffmpeg -y
     ```
   - **Arch Linux ユーザー:**
     ```bash
     sudo pacman -S ffmpeg uv
     ```

3. **インストールスクリプトを実行**
   ```bash
   ./install
   ```

**1. GUI** を選ぶと初回設定ウィザードへ進みます。**2. CLI** を選ぶとターミナルの設定メニューが開きます。

<a id="cli"></a>

## 3. CLI を使う

ターミナルを使いたい場合は、インストール時に **2. CLI** を選んでください。GUI と CLI は `config.json` を共有するため、チャンネルの再登録は不要です。

### チャンネル追加と設定

録画したい配信者を登録しないと録画は行われません。  
インストール直後に設定画面が閉じた場合は、Windows では `settings.bat`、Mac/Linux では `./settings` を実行してください。

1. メニューが表示されたら、キーボードの数字を押して選択します。
   - **`1` を入力して Enter**: Channel Settings（チャンネル設定）
   - **`1` を入力して Enter**: Add Channel（チャンネル追加）

2. **チャンネルの追加方法** を選択してください。
   - **チャンネル名で検索**：検索語を入力し、名前と ID が表示された結果から追加するチャンネルを選択します。
   - **チャンネル ID で直接追加**：CHZZK チャンネル URL の末尾にある ID を入力すると、公式チャンネル名が自動的に取得されます。

3. 取得された **チャンネル名と ID** を確認してください。
   - 登録済みの ID は検索結果に表示され、重複して追加できません。
   - 同じ名前の別の ID が登録済みの場合は既存 ID が表示されるため、同名チャンネルを区別できます。

4. **保存先** を入力してください。
   - 何も入力せず Enter を押すと、プロジェクト内に公式チャンネル名のフォルダーが作成され、そこに録画が保存されます。
   - 必要に応じて別のフォルダー名またはパスを入力できます。

5. 表示されたチャンネル名、ID、保存先が正しければ `Y` を入力してください。

> **ヒント:** 成人認証またはメンバーシップ認証が必要な配信を録画するには、設定メニューの **4. NAVER ログイン** で、新しい Chrome、Microsoft Edge、または Firefox ウィンドウから NAVER に直接ログインして Cookie（NID_AUT、NID_SES）を取得するか、Cookie 値を手動で入力してください。ブラウザログイン方式の初回利用時は、互換ドライバーの準備にインターネット接続が必要な場合があります。
> **2. 録画・画質**で形式・分割・解像度・FPS、**3. エンコード**で H.264/HEVC/AV1、**5. ネットワーク**で DoH、**6. 言語・ログ**で言語とファイルログを設定します。個別設定は **1. チャンネル管理 → 4. チャンネル別の分割・画質**にあります。`0` で戻るか終了します。

### 録画開始

あとはプログラムを起動したままにしておけば大丈夫です。

#### Windows

フォルダー内の `chzzk_record.bat` ファイルをダブルクリックしてください。

#### Mac / Linux

ターミナルで次のコマンドを入力してください。
```bash
./chzzk_record
```

黒いウィンドウが表示され、文字が出ていれば正常に動作しています。  
**このウィンドウを閉じると録画が止まるので、開いたままにしてください！**（最小化しても構いません。）

## よくある質問（FAQ）

**Q. 録画されたファイルはどこにありますか？**
A. 保存先を別途指定していなければ、プロジェクト内の公式チャンネル名フォルダーに保存されます。 GUI ではチャンネルを選び、**保存先を開く**で録画フォルダーを開けます。

**Q. プログラムを終了するにはどうすればよいですか？**
A. GUI では **録画設定 → アプリを完全に終了**を選ぶと、ファイルの処理後に終了します。ウィンドウを閉じる操作は既定ではトレイに隠します。CLI では実行中のターミナルで `Ctrl` + `C` を押してください。

**Q. エラーが発生します！**
A. [Issues](https://github.com/munsy0227/Chzzk-Rekoda/issues) にアクセスして症状を知らせていただければ、サポートできます。
