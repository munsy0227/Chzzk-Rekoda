# CHZZK Rekoda（Chzzk-Rekoda）

**言語:** [한국어](README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

Streamlink と FFmpeg を使用して作られた、Windows、macOS、Linux 対応の CHZZK 自動録画プログラムです。

また、パソコンに詳しくない方でも簡単に使える **CHZZK 自動録画プログラム**です。  
配信が始まると自動的に録画を開始し、配信が終了すると自動的に保存します。

[[チュートリアル] Android スマートフォンにプログラムをインストールする](https://github.com/munsy0227/Chzzk-Rekoda/discussions/17)

[[TUTORIAL] How to Install Chzzk-Rekoda in Android Systems](https://github.com/munsy0227/Chzzk-Rekoda/discussions/18)

## 1. インストール（ダウンロード）

使用している OS（Windows、Mac、Linux）に合った説明を読んで、手順に従ってください。
インストール中に言語選択画面が表示されたら、最初に使用したい言語を選択してください。

### Windows ユーザー

**ステップ 1: プログラムをダウンロード**
1. このページ上部にある緑色の **[Code]** ボタンを押してください。
2. メニューから **[Download ZIP]** を押して圧縮ファイルをダウンロードしてください。
3. ダウンロードしたファイルを解凍してください。（見つけやすい「デスクトップ」などをおすすめします。）

（Git を使用できる場合は Git を使用してください。）

**ステップ 2: インストーラーを実行**
1. 解凍したフォルダーに入ります。
2. `install.bat` ファイルを探してダブルクリックで実行してください。
3. 黒いウィンドウが表示され、必要なファイルが自動的にインストールされます。少し時間がかかる場合があるのでお待ちください。
4. インストールが完了すると、自動的に設定画面が表示されます。

---

### macOS / Linux ユーザー

**ステップ 1: ターミナルを開く**
- **Mac:** `Command` + `Space` キーを押し、「ターミナル」と検索して実行してください。
- **Linux:** 使用しているターミナルアプリを実行してください。

**ステップ 2: コマンドを入力**
以下のコマンドを 1 行ずつコピーしてターミナルに貼り付け、Enter を押してください。

1. **プログラムをダウンロード**
   ```bash
   git clone https://github.com/munsy0227/Chzzk-Rekoda.git
   cd Chzzk-Rekoda
   ```

2. **FFmpeg をインストール（録画に必須）**
   - **Mac ユーザー（Homebrew が必要）:**
     ```bash
     brew install ffmpeg
     ```
   - **Ubuntu/Debian ユーザー:**
     ```bash
     sudo apt install ffmpeg -y
     ```
   - **Arch Linux ユーザー:**
     ```bash
     sudo pacman -S ffmpeg uv
     ```

3. **インストールスクリプトを実行**
   ```bash
   ./install
   ```

## 2. 設定（チャンネル追加）

録画したい配信者を登録しないと録画は行われません。  
インストール直後に設定画面が閉じた場合は、Windows では `settings.bat`、Mac/Linux では `./settings` を実行してください。

1. メニューが表示されたら、キーボードの数字を押して選択します。
   - **`1` を入力して Enter**: Channel Settings（チャンネル設定）
   - **`1` を入力して Enter**: Add Channel（チャンネル追加）

2. **チャンネルの追加方法** を選択してください。
   - **チャンネル名で検索**：検索語を入力し、名前と ID が表示された結果から追加するチャンネルを選択します。
   - **チャンネル ID で直接追加**：CHZZK チャンネル URL の末尾にある ID を入力すると、公式チャンネル名が自動的に取得されます。

3. 取得された **チャンネル名と ID** を確認してください。
   - 登録済みの ID は検索結果に表示され、重複して追加できません。
   - 同じ名前の別の ID が登録済みの場合は既存 ID が表示されるため、同名チャンネルを区別できます。

4. **保存先** を入力してください。
   - 何も入力せず Enter を押すと、プロジェクト内に公式チャンネル名のフォルダーが作成され、そこに録画が保存されます。
   - 必要に応じて別のフォルダー名またはパスを入力できます。

5. 表示されたチャンネル名、ID、保存先が正しければ `Y` を入力してください。

> **ヒント:** 成人認証またはメンバーシップ認証が必要な配信を録画するには、設定メニューの **5. NAVER Cookie 設定** で、新しい Chrome、Microsoft Edge、または Firefox ウィンドウから NAVER に直接ログインして Cookie（NID_AUT、NID_SES）を取得するか、Cookie 値を手動で入力してください。ブラウザログイン方式の初回利用時は、互換ドライバーの準備にインターネット接続が必要な場合があります。
> 保存拡張子は **2. Recording Settings** で `ts`、`mkv`、`webm` から選択でき、同じメニューで録画ファイルを何時間または何分ごとに分割するかも設定できます。AV1 エンコードは **4. AV1 Settings** で有効にできます。DNS に問題がある場合は、**6. DNS-over-HTTPS Settings** で DoH アドレスを設定して有効にできます。言語は **8. Language Settings** で韓国語、英語、簡体字中国語、繁体字中国語、日本語から選択できます。

## 3. 録画を開始する

あとはプログラムを起動したままにしておけば大丈夫です。

### Windows
フォルダー内の `chzzk_record.bat` ファイルをダブルクリックしてください。

### Mac / Linux
ターミナルで次のコマンドを入力してください。
```bash
./chzzk_record
```

黒いウィンドウが表示され、文字が出ていれば正常に動作しています。  
**このウィンドウを閉じると録画が止まるので、開いたままにしてください！**（最小化しても構いません。）

## よくある質問（FAQ）

**Q. 録画されたファイルはどこにありますか？**
A. 保存先を別途指定していなければ、プロジェクト内の公式チャンネル名フォルダーに保存されます。

**Q. プログラムを終了するにはどうすればよいですか？**
A. 実行中の黒いウィンドウ（ターミナル）を閉じるか、ウィンドウをクリックした状態でキーボードの `Ctrl` + `C` を押すと終了します。

**Q. エラーが発生します！**
A. [Issues](https://github.com/munsy0227/Chzzk-Rekoda/issues) にアクセスして症状を知らせていただければ、サポートできます。
