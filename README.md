# 치지직 레코다 (Chzzk-Rekoda)


**현재 GUI 버전 제작 중에 있습니다. 안정적으로 작동이 됨을 확인하고 나면 main에 병합할 예정입니다.**


**언어:** [한국어](README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

Streamlink와 ffmpeg를 활용하여 만들어진 Windows, macOS, Linux를 지원하는 치지직 자동 녹화 프로그램입니다.

또한 컴퓨터를 잘 모르는 분들도 쉽게 사용할 수 있는 **치지직 자동 녹화 프로그램**입니다.  
방송이 켜지면 자동으로 녹화를 시작하고, 방송이 꺼지면 알아서 저장해줍니다.

새로운 기능 추가, 버그 수정, 성능 개선, 문서 보완 등 다양한 기여를 위한 [Pull Request](https://github.com/munsy0227/Chzzk-Rekoda/pulls)를 환영합니다.

## 1. GUI로 시작하기

기존 CLI와 같은 `config.json`을 사용하는 GUI를 실행할 수 있습니다.

1. [아래 설치 안내](#installation)에 따라 설치한 뒤, 마지막 선택 화면에서 **1. GUI**를 선택하세요. 설치가 끝나면 GUI가 열립니다.
2. 첫 GUI 실행에는 언어 선택 → 채널 검색·저장 폴더 확인 → 완료 순서의 마법사가 표시됩니다. 완료할 때 설정을 저장하며, 채널은 나중에 추가할 수도 있습니다. **도움말 → 처음 설정**에서 다시 열 수 있습니다.
3. **홈 → 자동 녹화 시작**을 누르세요. 자동 녹화가 켜진 채널의 방송을 기다렸다가 녹화를 시작합니다. 이후 채널은 **채널 추가**로 더 등록할 수 있습니다.

### 다음부터 GUI 열기

| 운영체제 | 실행 방법 |
| --- | --- |
| Windows | `chzzk_gui.vbs` 더블 클릭 · CMD 창 없이 실행 (`chzzk_gui.bat`도 같은 실행기를 사용) |
| Linux | `Chzzk-Rekoda.desktop` 더블 클릭 · 실행 허용을 물으면 허용 |
| macOS | 설치 폴더의 터미널에서 `./chzzk_gui` 실행 |

macOS/Linux에서는 `./chzzk_gui`도 사용할 수 있습니다. 기존 CLI 설치에 GUI를 추가하거나 uv로 직접 실행하려면 다음 명령을 사용하세요. Qt는 GUI를 사용할 때만 필요합니다.

```bash
uv run --extra gui chzzk_gui.py
```

### 리본에서 설정 바꾸기

| 원하는 작업 | 메뉴 |
| --- | --- |
| 저장 형식·분할 간격 | **녹화 설정 → 기본 녹화** |
| 해상도·FPS | **녹화 설정 → 화질** |
| H.264 · HEVC · AV1 인코딩 | **녹화 설정 → H.264 / HEVC / AV1** |
| 채널별 저장 폴더·분할·화질 | **채널 우클릭 → 채널 편집** |
| 로그인 쿠키 가져오기 | **녹화 설정 → 네이버 로그인** |
| 언어·로그·백그라운드 동작 | **녹화 설정 → 앱 · 백그라운드** |
| 녹화 정리 후 앱 종료 | **녹화 설정 → 프로그램 완전 종료** |

설정은 **설정 저장**을 눌러 적용하세요. 항목 위에 포인터를 잠시 두거나 설명 버튼/F1을 사용하면 도움말을 볼 수 있습니다.

### 네이버 로그인이 필요한 방송

GUI는 데스크톱 환경과 FFmpeg가 필요합니다. **로그인 창 열기**는 CLI의 브라우저 로그인 절차를 바로 실행합니다. 브라우저에서 로그인한 뒤 열린 CLI 창에서 Enter를 누르면 쿠키가 GUI로 전달되며, **설정 저장**으로 적용합니다. GUI 자체의 CMD 창은 숨겨지고 로그인할 때만 별도의 CLI 창이 열립니다.

<details>
<summary>지원 화질·코덱, 미리보기·트레이 등 자세한 기능 보기</summary>

- 리본 메뉴에서 채널 이름 검색·ID 조회, 추가·편집·등록 해제 및 모든 녹화 설정을 조정합니다. 설정에 포인터를 잠시 두거나 F1/설명 버튼을 사용하면 도움말을 볼 수 있습니다.
- CHZZK 프로필 이미지가 있으면 채널 아이콘으로 표시합니다. 이미지 조회가 실패하면 이름의 첫 글자를 표시합니다.
- 선택한 녹화 채널의 **현재 저장 파일에서 추출한 화면을 5초마다 갱신**합니다. 소리는 재생하지 않으며, 데이터가 부족하거나 프레임을 읽지 못하면 안내 후 재시도합니다. 미리보기를 꺼도 녹화는 계속됩니다.
- 기본적으로 창을 닫으면 시스템 트레이에서 계속 녹화합니다. 아이콘으로 창을 다시 열거나 **종료**할 수 있습니다. 앱 설정에서 이 동작을 끌 수 있으며 트레이가 없는 환경에서는 창 닫기로 종료합니다. 같은 프로젝트의 CLI/GUI 중복 녹화와 설정 덮어쓰기 충돌을 방지합니다.
- 저장한 녹화 옵션은 새 녹화 작업부터 적용됩니다. 실행 중인 녹화기의 DNS·파일 로그 설정은 녹화기를 중지 후 다시 시작하면 적용됩니다.

- 채널 이름과 상태 사이에 원본 방송 제목을 표시합니다. 채널을 우클릭하면 설정·등록 해제·저장 폴더 열기·자동 녹화 활성화를 바로 조정합니다.
- 분할 간격과 화질은 전체 기본값 또는 채널별 값으로 설정할 수 있습니다. 채널의 ‘전체 설정 사용’은 기본값을 따르며 분할 ‘사용 안 함’은 그 채널만 한 파일로 저장합니다.
- `144p`, `360p`, `480p`, `720p60`, `1080p60`은 실제 제공되는 스트림을 직접 받습니다. 다른 해상도는 인코딩하며, FPS만 다르면 같은 해상도의 스트림을 받아 프레임을 변환합니다. 변환에는 선택한 코덱을 사용하고 미선택 시 H.264(WebM은 VP9)를 사용합니다. 제공되지 않는 화질은 가까운 상위 화질 또는 최고 화질을 받아 변환합니다.
- H.264는 libx264/NVENC/QSV/AMF/VAAPI/VideoToolbox를 지원하며 HEVC·AV1과 하나만 선택합니다. 하드웨어 실패 시 libx264를 시도합니다. H.264+WebM은 MKV로 저장합니다.
- 파일명이 길어 제목이 축약·해시 처리된 경우에만 영상 또는 각 분할 파일 옆에 원본 제목을 UTF-8 `.txt`로 제공합니다. 짧은 제목에는 TXT를 만들지 않습니다.
- GUI는 `font/02_NotoSansCJK-TTF-VF/Variable/OTC/NotoSansCJK-VF.ttf.ttc`를 사용하며 언어별 KR/JP/SC/TC 글꼴을 선택합니다. Windows는 DirectWrite와 모니터별 DPI를 사용합니다. 배포 폴더에 `LICENSE`를 함께 제공합니다.
- **녹화 설정 → 프로그램 완전 종료**는 녹화 파일 정리를 기다린 뒤 트레이까지 종료합니다. 분할 녹화의 용량은 현재 작업에서 만든 모든 분할 파일의 실제 크기를 합산한 값입니다.
- GUI 녹화가 중지되면 로그에 중지 명령·프로그램 종료·통신 연결 끊김 등의 원인을 구분해 표시합니다. 파일 로그가 켜져 있으면 설정 파일 옆 `log.log`에서도 확인할 수 있습니다.
- 프로그램 아이콘은 창·작업표시줄·트레이에서 동일하게 사용합니다. Windows에서 `chzzk_gui.vbs`를 실행하면 설치 폴더에 아이콘이 적용된 **`Chzzk Rekoda.lnk`** 바로가기가 생성됩니다. Linux는 GUI 실행 시 사용자 앱 목록에 아이콘과 실행 항목을 등록합니다.

## 2. 설치하기

**[프로그램 ZIP 다운로드](https://github.com/munsy0227/Chzzk-Rekoda/archive/refs/heads/main.zip)** · **[GitHub 저장소](https://github.com/munsy0227/Chzzk-Rekoda)**

사용하고 계신 운영체제(윈도우, 맥, 리눅스)에 맞는 설명을 읽고 따라해주세요.
설치 중 언어 선택 화면이 나오면 원하는 언어를 먼저 선택하세요.

### 🪟 윈도우 (Windows) 사용자

**1단계: 프로그램 다운로드**

1. 위 **프로그램 ZIP 다운로드**를 누르거나, GitHub 저장소에서 초록색 **[Code]** 버튼을 누르세요.
2. Code 메뉴를 이용했다면 **[Download ZIP]**을 눌러 압축 파일을 받으세요. 위의 직접 다운로드 링크를 눌렀다면 이 단계는 건너뛰세요.
3. 다운로드한 파일의 압축을 풀어주세요. (찾기 쉬운 '바탕화면' 등을 추천합니다.)

(Git을 사용하실 수 있다면 Git을 사용하세요.)

**2단계: 설치 프로그램 실행**

1. 압축을 푼 폴더 안으로 들어갑니다.
2. `install.bat` 파일을 찾아 더블 클릭해서 실행하세요.
3. 검은 창이 뜨고 필요한 파일들을 자동으로 설치합니다. 시간이 조금 걸릴 수 있으니 기다려주세요.
4. 설치 마지막에 **GUI / CLI**를 선택하세요. GUI는 설치를 마치고 창을 열며, CLI는 기존 터미널 설정 메뉴를 시작합니다.

---

### 🍎 맥(macOS) / 🐧 리눅스(Linux) 사용자

**1단계: 터미널 열기**

- **Mac:** `Command` + `Space` 키를 누르고 "터미널"이라고 검색해서 실행하세요.
- **Linux:** 사용하시는 터미널 앱을 실행하세요.

**2단계: 명령어 입력하기**
아래 명령어들을 한 줄씩 복사해서 터미널에 붙여넣고 엔터(Enter)를 누르세요.

1. **프로그램 다운로드**
   ```bash
   git clone https://github.com/munsy0227/Chzzk-Rekoda.git
   cd Chzzk-Rekoda
   ```

2. **FFmpeg 설치 (녹화에 꼭 필요해요)**
   - **Mac 사용자 (Homebrew 필요):**
     ```bash
     brew install ffmpeg
     ```
   - **Ubuntu/Debian 사용자:**
     ```bash
     sudo apt install ffmpeg -y
     ```
   - **Arch Linux 사용자:**
     ```bash
     sudo pacman -S ffmpeg uv
     ```

3. **설치 스크립트 실행**
   ```bash
   ./install
   ```

실행 방식 선택에서 **1. GUI**를 선택하면 첫 설정 마법사로 이어집니다. **2. CLI**를 선택하면 터미널 설정 메뉴가 열립니다.

## 3. CLI로 사용하기

터미널 방식이 편하다면 설치할 때 **2. CLI**를 선택하세요. GUI와 CLI는 같은 `config.json`을 사용하므로 채널을 다시 등록할 필요가 없습니다.

### 채널 추가와 설정

녹화하고 싶은 스트리머를 등록해야 녹화가 됩니다.  
설치 직후 설정 화면이 꺼졌다면 `settings.bat`(윈도우) 또는 `./settings`(맥/리눅스)를 실행하세요.

1. 메뉴가 나오면 키보드 숫자를 눌러 선택합니다.
   - **`1` 입력 후 엔터**: 채널 설정 (Channel Settings)
   - **`1` 입력 후 엔터**: 채널 추가 (Add Channel)

2. **채널 추가 방식**을 선택하세요.
   - **채널 이름으로 검색**: 검색어를 입력하고 이름과 ID가 함께 표시된 결과에서 추가할 채널을 선택합니다.
   - **채널 ID로 직접 추가**: 치지직 채널 URL 끝의 ID를 입력하면 공식 채널 이름을 자동으로 조회합니다.

3. 검색되거나 조회된 **채널 이름과 ID를 확인**하세요.
   - 이미 등록된 ID는 검색 결과에 표시되며 중복 추가되지 않습니다.
   - 같은 이름의 다른 ID가 등록되어 있으면 기존 ID를 보여 주므로 동명이인 채널을 구분할 수 있습니다.

4. **저장 경로**를 입력하세요.
   - 아무것도 입력하지 않고 엔터를 치면 프로젝트 안에 공식 채널 이름의 폴더가 생성되고 그곳에 저장됩니다.
   - 필요한 경우 다른 폴더 이름이나 경로를 직접 입력할 수 있습니다.

5. 표시된 채널 이름, ID, 저장 경로가 맞다면 `Y`를 입력하세요.

> **팁:** 성인 인증이나 멤버십 인증이 필요한 방송을 녹화하려면 설정 메뉴의 **4. 네이버 로그인**에서 Chrome, Microsoft Edge 또는 Firefox로 NAVER에 직접 로그인해 쿠키(NID_AUT, NID_SES)를 가져오거나 쿠키값을 수동으로 입력하세요. 브라우저 로그인 방식은 새 브라우저 창을 사용하며, 첫 실행 시 호환 드라이버 준비를 위해 인터넷 연결이 필요할 수 있습니다.
> **2. 녹화 · 화질**에서 파일 형식·분할·해상도·FPS를 설정합니다. **3. 인코딩**에서 H.264/HEVC/AV1을 선택하고, **5. 네트워크**에서 DoH를, **6. 언어 · 로그**에서 언어와 파일 로그를 바꿉니다. **1. 채널 관리 → 4. 채널별 분할 · 화질**은 채널별 설정입니다. `0`은 뒤로 또는 종료입니다.

### 녹화 시작

이제 프로그램을 켜두기만 하면 됩니다.

#### 🪟 윈도우

폴더에 있는 `chzzk_record.bat` 파일을 더블 클릭하세요.

#### 🍎 맥 / 🐧 리눅스

터미널에서 다음 명령어를 입력하세요.
```bash
./chzzk_record
```

검은 창이 떠 있고 글자들이 나온다면 정상적으로 작동 중인 것입니다.  
**이 창을 끄면 녹화가 멈추니 켜두세요!** (최소화 해두셔도 됩니다.)

## ❓ 자주 묻는 질문 (FAQ)

**Q. 녹화된 파일은 어디에 있나요?**
A. 저장 경로를 따로 지정하지 않았다면, 프로젝트 안의 공식 채널 이름 폴더에 저장됩니다. GUI에서는 채널을 선택하고 **저장 폴더 열기**를 누르면 바로 열 수 있습니다.

**Q. 프로그램을 끄려면 어떻게 하나요?**
A. GUI는 **녹화 설정 → 프로그램 완전 종료**를 누르면 파일 정리 후 종료됩니다. 창 닫기는 기본적으로 트레이로 숨깁니다. CLI는 실행 중인 터미널에서 `Ctrl` + `C`를 누르세요.

**Q. 오류가 발생해요!**
A. [이곳(Issues)](https://github.com/munsy0227/Chzzk-Rekoda/issues)에 들어가서 증상을 알려주시면 도와드릴 수 있습니다.

### 📌 저작권 관련 예시 (라디유)
- 저작권은 라디유의 의사로 샌드박스 네트워크에 위임되었습니다.
- AI 학습 자료로 사용하는 행위 역시 저작권 침해입니다.
- 클립은 공식 팬 커뮤니티를 제외하고는 다른 곳에 올릴 수 없습니다. (공개 또는 비공개에 국한되지 않음)
- 가이드라인을 준수했다 해도 라디유 또는 샌드박스 네트워크 측의 판단으로 삭제될 수 있습니다.

### 🚫 비공식 프로젝트 안내
본 프로젝트와 기여자는 **네이버(NAVER)**, **치지직(CHZZK)** 또는 그 계열사 및 자회사와 어떠한 제휴, 권한 부여, 승인 또는 공식적인 연결 관계도 없음을 밝힙니다. 본 프로젝트는 편의를 제공할 목적으로 개발된 독립적이고 비영리적인 비공식 프로그램입니다.

### ™️ 상표권 안내
"치지직(CHZZK)", "네이버(NAVER)"라는 명칭을 포함하여 관련 명칭, 마크, 엠블럼 및 이미지는 해당 소유자의 등록 상표입니다. 이러한 상표의 사용은 식별 및 참조 목적으로만 사용되며, 상표권자와의 어떠한 연관성도 시사하지 않습니다. 본 프로젝트는 해당 상표권을 침해하거나 상표권자에게 피해를 줄 의도가 없음을 명시합니다.

### 📜 저작권 및 약관 준수
본 프로젝트는 스트리밍 영상, 오디오 또는 기타 제3자 콘텐츠의 소유권을 주장하지 않으며, 해당 콘텐츠에 대한 라이선스를 부여하지도 않습니다. 사용자는 관련 저작권법, 플랫폼 정책(치지직 이용약관 등), 현지 법령을 직접 확인하고 준수할 책임이 있으며, 본 프로젝트를 이용한 저장, 복제, 배포, 송신 또는 상업적 이용에 대한 책임은 전적으로 사용자에게 있습니다.
