# 전체 설정 리본 시안

## 요청과 범위

- 기존 리본 UI의 느낌을 유지하면서 모든 설정을 구현해 달라는 요청.
- 사용자가 선택 질문에 `리본 시안의 모든 설정 완성`이라고 답했다. 이후 `계속 이어서 해줘`는 동일 작업의 계속 진행 요청이다.
- 실제 Qt 코드, 설정 파일, 브라우저 인증 정보는 이번 작업에서 변경하지 않는다.

## 구현

- `settings.py`의 CLI 메뉴, `default_config`, `normalize_config`, 인코더/프리셋 상수를 확인하고 [대응표](../plans/gui-settings-coverage.md)를 작성했다.
- 시안: `/home/munsy0227/.codex/visualizations/2026/09/06/01a07736-72fe-7c12-be48-6b80c70db9fe/rekoda-ribbon-settings.html`.
- 기존 리본 스타일을 유지하고 기본 녹화, HEVC, AV1, 네이버 로그인, 네트워크, 언어/로그 화면을 추가했다.
- 파일 형식, 분할 단위, 확인 간격, 다운로드 스레드, 인코더별 프리셋, 두 비트레이트, 인코딩 활성화, 쿠키 표시/삭제, DoH 주소/복원, 5개 언어 선택값, 로그 저장을 구현했다.
- 예시 채널의 이름/ID 검색, 중복 방지, 추가, 표시 이름/저장 폴더/시작 지연 편집, 활성화와 등록 해제를 구현했다.
- 설정은 시안 안의 임시 값으로 유지한다. 분류를 이동해도 유지하며 저장/취소가 가능하다. 실제 로그인이나 인증 성공을 표시하지 않는다.

## 검증

- 기본 설정: 범위 밖 스레드 수 거부, 확인 간격/90분 분할/스레드 저장, 수정 후 취소 시 저장값 복원 확인.
- 인코딩: NVENC 전환 후 p4 및 19개 HEVC 프리셋, SVT-AV1 -2~13 범위, 잘못된 비트레이트 거부, 단위 없는 4000 입력의 4000k 저장, AV1 활성화 시 HEVC 해제 확인.
- 네트워크/프로그램: HTTP DoH 주소 거부, 기본 HTTPS 주소 복원, 5개 언어 선택값 및 로그 저장 토글 확인.
- 로그인: Chrome/Edge/Firefox 목록과 연결 전 안내, 예시 쿠키만 사용한 마스킹/표시/삭제/취소 복원 확인. 실제 쿠키는 사용하지 않았다.
- 채널: 예시 검색과 추가로 3→4개 증가, 잘못된 지연 거부, 경로/지연 저장, 등록 해제 후 취소 복원, ID 조회 결과의 등록됨 버튼 비활성화 확인.
- 초기 JS의 하이픈 포함 키 따옴표 누락을 수정한 후 화면 초기화를 확인했다.
- `settings.py`를 실행하거나 가져오지 않고 AST에서 설정 상수만 추출해 대조했다. 예시 채널/지연을 제외한 전체 기본값, 인코더 12종, 프리셋 목록 9개, 인코더별 기본 프리셋 12개, 언어 5개가 일치했다.
- HEVC VideoToolbox와 AV1 VAAPI 선택 시 `auto` 프리셋 비활성화, 키보드로 채널 지연을 비운 뒤 다른 화면에서 저장해도 오류 표시, 잘못된 빈 입력 보존 및 취소 복원, F1 상세 설명을 확인했다.
- 1024/736px 화면 및 360/320px 작은 화면에서 배치를 확인했다. 작은 화면은 리본과 입력을 줄바꿈하며 모든 설정 분류와 채널/홈 화면의 가로 넘침이 없었다. 라이트/다크 화면을 확인했다.
- 브라우저 실행 오류/경고 없음. 실제 Qt 실행, 실제 로그인, 실제 녹화 및 하드웨어 인코더 probe는 이번 시안 검증 대상이 아니다.
- `git diff --check`, 시안의 HTML 조각 형식/ID 중복/외부 API 호출 없음, `.ai` 문서 링크와 공백 검사를 통과했다.

## 후속 구현 시 유의

- 시안에 모든 설정 입력을 제공하는 것과 실제 Qt 구현은 구분한다. 폴더 선택, 외부 채널 검색, 브라우저 로그인, 파일 저장 및 실제 5개 언어 UI 전환은 연결 전이다.
- 실제 GUI는 동일한 CLI 설정 코어를 공유해야 한다. 기존 저장 실패/손상 파일 보존, 마지막 유효 설정 유지, FFmpeg 안전 종료를 유지한다.
