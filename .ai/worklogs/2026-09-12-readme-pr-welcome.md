# README Pull Request 환영 문구 추가

확인 날짜: 2026-09-12

- 사용자 요청: README에 기능 추가 등 다양한 Pull Request를 환영한다는 문구 추가.
- 변경 파일: README.md, README.en.md, README.zh-CN.md, README.zh-TW.md, README.ja.md.
- 변경 내용: 소개 문단과 Android 튜토리얼 링크 사이에 기능 추가, 버그 수정, 성능 개선, 문서 보완 기여를 환영하는 한 문장을 각 언어로 추가. Pull Request 텍스트는 저장소 /pulls로 연결.
- 결정: 기존 소개, 튜토리얼, 문서 구성을 보존하고 동일 위치에 최소 문구만 추가.
- 검증: GitHub API로 변경 후 5개 파일을 다시 읽어 예상 전체 내용과 일치함을 확인. 코드 변경이 없어 실행 테스트는 수행하지 않음. 브라우저 렌더링 및 git diff --check는 미실행.
