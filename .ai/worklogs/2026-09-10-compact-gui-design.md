# 리본 GUI 디자인과 공간 정리

## 요청과 방향

- 2026-09-10: 사용자가 최신 디자인 느낌으로 GUI를 다듬고 메뉴의 빈 공간을 줄이도록 요청했다. 시작 HEAD는 `b7def72`이며 개인 녹화 폴더 외의 변경이 없었다. 디자인 구현을 진행했으며 이번 요청에는 별도 커밋·푸시 지시가 없다.
- [Fluent 2 Layout](https://fluent2.microsoft.design/layout)의 간격·그룹화 원칙과 [Toolbar](https://fluent2.microsoft.design/components/web/react/core/toolbar/usage)의 한 줄 명령/더보기 방식을 참고했다. 기존 리본 탭과 모든 설정을 유지하고, 명령의 세로 배치와 반복 그룹 제목을 줄이는 방향을 택했다.

## 변경

- `gui/window.py`: 각 리본 탭의 `QGroupBox`/큰 세로 버튼을 아이콘 옆 텍스트와 구분선이 있는 `QToolBar`로 바꿨다. 넘치는 명령은 Qt 확장 메뉴에 들어간다. `QAction`에 기존 콜백과 활성 상태를 연결해 더보기 메뉴에서도 시작/중지 동작이 일치한다. 모든 명령의 접근성 이름과 도움말을 유지하고 키보드 포커스 도움말을 연결했다.
- 한국어 1180×820, 기본 Qt offscreen 배율의 변경 전후 측정: 리본 135→83px, 표 시작 위치 y=195→135, 채널 행 64→52px, 로그 최대 높이 165→140px. 언어/배율/실제 OS 글꼴 측정에 따라 논리 픽셀 값은 조금 달라질 수 있다.
- 헤더에 앱 아이콘과 녹화 상태 배지를 배치했다. 표는 왼쪽 정렬 헤더, 옅은 줄무늬, 민트 선택색으로 정돈했다. 미리보기 사용 체크박스를 패널 헤더로 옮기고 제목·갱신 시간을 한 줄에 배치했다. 비어 있는 갱신 시간은 숨긴다. 로그는 접힘 화살표를 표시하고 UI 재구성 후에도 로그 내용과 접힘 상태를 보존한다.
- `gui/theme.py`: 밝은/어두운 화면의 색상, 6~10px 모서리, 입력·호버·포커스·선택·비활성 상태, 메뉴와 설정 화면 스타일을 한곳에서 관리한다. `gui/icons.py`의 직접 작성한 SVG 경로를 QtSvg로 여러 크기에 렌더링하여 명령 아이콘의 선 굵기와 색을 통일한다. `assets/controls/chevron-{up,down}.svg`는 드롭다운/스핀 입력의 화살표다. 새 외부 패키지는 추가하지 않았다.
- `gui/common.py`: 더보기 버튼의 논리 폭을 32px로 확보했다. `ElidedLabel`은 긴 제목을 한 줄로 줄이며 전체 내용은 HTML 이스케이프한 툴팁으로 제공한다. 방송 제목 원문이나 저장 규칙은 바꾸지 않았다.
- `gui/settings_dialog.py`: 설정 폼의 세로 간격 16→10px, 여백과 탐색 목록 선택 스타일을 정리했다. `i18n.py`에는 더보기 접근성/도움말 문구 `gui.more_actions`를 5개 언어로 추가했다. 녹화 엔진, 설정 형식, 폰트, PNG/ICO와 실행기는 수정하지 않았다.

## 검증

- 임시 설정과 합성 채널을 사용하는 `/tmp/rekoda_design_check.py`로 Qt offscreen 검증을 수행했다. 개인 설정이나 네트워크 방송은 사용하지 않았다. 검증 전후 임시 설정 파일 바이트가 같음을 확인했다. 임시 스크립트는 커밋 대상이 아니다.
- 한국어/영어/간체/정체/일본어 × 760×600 및 1180×820 × 리본 4개 탭 × 100/150/200% 배율 통과. 넘친 명령이 실제 확장 팝업에 포함되는지와 팝업의 앱 설정 콜백 실행, 툴팁, 번역 키, 설정 8개 페이지와 스핀 버튼 클릭을 확인했다.
- 시작/실행/중지 상태의 액션 활성 여부, 시작 콜백, 로그 접기 및 UI 재구성, 긴 제목의 생략/툴팁 이스케이프, 영상 프레임과 갱신 시간 표시, 밝은/어두운 테마를 검증했다. 초기 점검에서 더보기 아이콘이 패딩에 가려지는 현상과 좁은 창의 제목/영상 겹침을 발견해 각각 확장 버튼 폭·패딩과 캡션 행 구성으로 수정했다.
- 스핀 클릭 검증의 초안은 값을 바꾼 상태로 취소해 정상적인 미저장 확인 창에서 대기했다. 검증 프로세스를 중단하고 원래 값으로 복원한 뒤 취소하도록 수정했다. 런타임의 저장 확인 동작은 변경하지 않았다.
- 최종 UI 캡처: `.gui-validation/design-refresh/light-final.png`, `dark-final.png`, `ribbon-final.png`, `settings-final.png`, `settings-dark-final.png`. 언어/좁은 창 캡처는 같은 폴더의 `{language}-{width}.png`; 배율별 결과는 `design-refresh-1.5/`, `design-refresh-2/`다. 실제 Qt 렌더를 시각 점검했으며 녹화 상태/로그는 검증용 합성 예시다.
- Python 문법 컴파일, 변경 GUI 모듈의 Ruff E9/F/I·포맷, `git diff --check` 통과. 기존 Windows 녹화 정상 확인과 구분하여, 이번 디자인의 Windows/macOS 실환경 및 실제 녹화는 직접 재검증하지 않았다.

## 구현 참고

- [Qt QToolBar](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QToolBar.html): QAction 기반 도구 모음과 공간 부족 시 확장 메뉴.
