확인 날짜: 2026-09-11~12.

## 요청과 변경

- 사용자 요청: 첨부한 GUI/CLI 화면을 README 맨 위에 넣고 GUI 설정부터 안내하도록 꾸미기.
- `README.md`, `README.en.md`, `README.zh-CN.md`, `README.zh-TW.md`, `README.ja.md`에 같은 구성을 적용했다.
- 사용자 첨부 Photo 2(GUI)는 `assets/screenshots/gui-recording.jpg`, Photo 1(CLI)는 `assets/screenshots/cli-recording.jpg`로 원본 그대로 복사했다. 상단에 GUI를 더 크게 배치하고 두 이미지를 누르면 원본을 열도록 연결했다.
- GUI 첫 설정/실행 방법과 리본 설정 위치 표를 먼저 배치했다. 설치, CLI, FAQ로 이동하는 고정 앵커를 추가하고 상세 GUI 기능은 펼쳐보기로 묶었다. 기존 CLI 명령, GUI 기능 목록, 고지 문구는 보존했다.
- 설치 ZIP과 clone 예시는 `gui` 브랜치로 지정했다. 당시 로컬 `origin/main`에는 GUI 진입점이 없으므로 기본 브랜치를 받는 혼동을 줄이기 위한 변경이다. 원격 브랜치를 새로 조회한 결과는 아니다.
- 안내는 `scripts/finish_install.py`, `chzzk_gui`, `gui/setup_wizard.py`, `gui/window.py`와 `i18n.py`의 실제 메뉴 이름을 대조했다.

## 검증 결과와 범위

- CommonMark/HTML 파싱으로 5개 문서의 이미지 경로, 내부 링크/앵커, GUI 우선 순서, 기존 CLI 명령과 기능/고지 보존을 확인했다.
- 9월 11일 복사 직후 두 이미지의 SHA-256이 첨부 원본과 일치했다. 12일 재검사에서는 문서 5개가 모두 통과했으나 임시 첨부 경로가 사라져 원본 해시 비교만 재실행하지 못했다. 저장소 안의 이미지 두 개는 유지되며 렌더링에서 정상 로드됐다.
- Qt WebEngine으로 로컬 HTML 미리보기를 1120px/390px 폭에서 렌더링했다. 이미지 로딩, 본문 가로 넘침 없음, 섹션 이동, 상세 기능 펼치기를 확인하고 상단·GUI 안내·작은 화면 캡처를 눈으로 확인했다.
- 샌드박스에서는 Qt 내부 통신이 차단됐으므로 외부 콘텐츠 접근을 차단한 로컬 렌더링을 승인된 실행 환경에서 검증했다. GitHub와 비슷한 스타일의 로컬 미리보기이며 실제 GitHub 페이지 게시/렌더링 확인은 아니다.
- `git diff --check` 통과. 검증 스크립트와 캡처는 기존 무시 경로 `.gui-validation/`에만 두었다. 프로그램 실행 코드는 변경하지 않았다.

## 후속 수정: main 병합 이후를 기준으로 설치 안내 변경

- 사용자 요청: `gui` 브랜치를 `main`에 병합할 예정이므로 앞서 변경한 URL을 되돌리기.
- 5개 언어 README의 다운로드를 `main.zip`으로 바꾸고, 브랜치 전용 링크 대신 저장소 루트 URL을 사용했다. clone 명령에서 `--branch gui`를 제거하고 GUI 브랜치 전용 안내와 다운로드 명칭도 함께 정리했다.
- 5개 문서 모두 main ZIP/저장소 URL/기본 clone 명령을 확인했다. 이전 `gui.zip`, `tree/gui`, `--branch gui`와 GUI 브랜치 문구가 남아 있지 않음을 검사했고 `git diff --check`도 통과했다.
- `.ai/KNOWLEDGE.md`의 설치 안내 기준을 갱신했다. 이 변경은 병합 이후를 위한 문서 준비이며, 실제 병합·커밋·푸시는 수행하지 않았다.

## 후속 수정: 기존 소개와 Android 튜토리얼 유지

- 사용자 요청: Streamlink/FFmpeg 기반 및 지원 OS 설명, 초보자도 쉽게 사용할 수 있다는 소개, 자동 녹화/저장 설명과 기존 Android 튜토리얼 2개를 유지하기.
- 5개 언어 README의 기존 소개 문단을 `git show HEAD:README*.md`에서 원문 그대로 복원했다. 아래쪽으로 이동했던 튜토리얼 링크를 소개 바로 다음으로 돌리고 중복된 하단 구역은 제거했다.
- 스크린샷은 맨 위, 첫 설정 안내는 GUI부터 시작하며 `main.zip`과 기본 clone 안내를 유지한다.
- 원문 문단 일치, 두 튜토리얼 URL이 상단에 각각 한 번만 존재함, GUI 우선 순서 및 main 다운로드 유지 검증이 5개 언어 모두 통과했다. `git diff --check`도 통과했다. 문구/위치만 수정했으며 웹 페이지의 실제 렌더링은 다시 확인하지 않았다.
