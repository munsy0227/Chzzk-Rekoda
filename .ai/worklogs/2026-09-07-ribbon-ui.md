- 설정 위에 잠시 포인터를 놓으면 나타나는 설명.

## 수행 및 결정

- `.ai/AGENTS.md`, `.ai/KNOWLEDGE.md`, `.ai/plans/qt-gui.md`에 사용자 확정 요구사항을 반영했다.
- 홈/채널/녹화 설정/도움말 리본, 중앙 채널 목록, 고급 설정 분리, 키보드 도움말 경로를 설계했다.
- 실제 Qt 도움말은 약 700ms 지연을 권장했다. 이 수치는 사용자 지정값이 아닌 초기 설계값이며 대화 시안의 기본 도움말 표시 지연도 700ms다.
- Qt 공식 QToolTip/QStyle 문서를 확인했다. 리본은 PySide6 Widgets 조합을 권장하고 공용 코어에는 Qt 의존성을 넣지 않는다.
- 현재 `settings.py`의 import 시 설정 로드 및 메뉴 실행과 `chzzk_record.py`의 전역 초기화를 다시 확인했다. 공용 모듈을 먼저 분리해야 한다는 기존 분석은 유효하다.
- 대화에서 리본 탭과 도움말, 설정 변경, 녹화 상태 전환을 살펴볼 수 있는 시안을 만들었다. 예시 데이터만 사용하며 실제 설정이나 녹화기를 조작하지 않는다.
- 시안 위치: `/home/munsy0227/.codex/visualizations/2026/09/06/01a07736-72fe-7c12-be48-6b80c70db9fe/rekoda-ribbon.html` (현재 작업에 할당된 시각화 폴더).

## 검증 및 다음 작업

- 문서 7개의 내부 링크 9개, 개행/공백 및 `git diff --check`를 확인했다. 시안의 ID 중복과 참조, HTML fragment 형식 및 크기도 확인했다.
- 브라우저에서 리본 화살표 키 탐색, 설정값 변경/저장, 포커스 툴팁, 설명 버튼과 F1 도움말, 안전한 중지의 저장 중/완료 상태 전환을 확인했다.
- 채널 추가 버튼이 도움말 닫기 버튼 스타일을 잘못 상속받는 문제를 수정했다. 최종 시안에서 채널 수가 3개에서 4개로 증가하는 것을 다시 확인했다.
- 데스크톱 화면과 약 345px/750px 폭에서 배치를 확인했다. 좁은 화면에서 리본이 줄바꿈되며 검사한 입력/버튼의 가로 잘림이 없었다. 검사 시 브라우저 스크립트 오류는 없었다.
- 포인터 도움말 지연은 제공된 표시 코드의 700ms 설정을 확인했으며 실제 마우스 지연 시간을 계측한 것은 아니다. Qt 플랫폼별 지연과 다크 모드 시각 검증은 후속 구현에서 확인한다.
- 실제 Qt 창/녹화 연결과 5개 언어 UI 적용은 아직 구현하지 않았다. 한국어 시안 문구를 제품에 반영할 때 모든 지원 언어를 함께 추가한다.
- 다음 구현은 설정 처리 공용화 → 리본 창과 도움말 → 녹화기 상태/명령 연결 순서로 진행한다.
